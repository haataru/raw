# Roadmap (Планы развития)

Здесь собраны глобальные фичи, которые превратят `rawDB` в полноценную Production-Ready систему уровня лучших мировых баз данных.

## 1. Поддержка JOIN (В процессе разработки)
- Реализация `INNER JOIN` через Hash Join алгоритм.
- Поддержка синтаксиса `SELECT * FROM A JOIN B ON A.id = B.a_id`.
- Оптимизация для колоночного движка (построение хеш-таблицы по одной колонке, фильтрация (probe) по другой).

## 2. PostgreSQL Wire Protocol (Сетевой сервер)
- Легковесный TCP-сервер, который парсит бинарный протокол Postgres.
- Позволит подключаться к базе через стандартные утилиты (`psql`, `DBeaver`) и драйверы (`psycopg2`, `asyncpg`).
- Отвяжет пользователей от необходимости использовать C API или встроенный Python модуль для сетевых приложений.

## 3. Интерактивный CLI-клиент (REPL)
- Отдельный бинарник `rawdb-cli`.
- Автодополнение команд (readline/linenoise).
- Подсветка синтаксиса.
- Форматированный табличный вывод результатов, замер времени выполнения запросов.

## 4. Векторизация и SIMD (AVX2/AVX-512)
- Векторное исполнение `WHERE` (сканирование чанками по 1024-4096 строк).
- Использование SIMD-инструкций для применения предикатов (`>`, `<`, `=`) сразу на пачках чисел.
- Пропуск целых блоков (Zone Maps / Min-Max индексы на уровне страниц).

## 5. Тип данных JSON
- Нативный тип данных `JSON` (хранение в бинарном формате наподобие JSONB).
- SQL-операторы для извлечения данных (например, `column->'key'->>'value'`).
- Индексация полей внутри JSON.
