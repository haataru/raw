# rawDB Command Line Interface (CLI)

`rawdb_cli` — это минималистичный и мощный интерактивный терминал (REPL) для работы с базой данных `rawDB`. Он позволяет выполнять SQL-запросы, управлять таблицами и просматривать данные в удобном табличном виде, не написав ни строчки кода на C++.

## Запуск

CLI собирается как исполняемый файл `rawdb_cli` вместе со всем проектом (см. [Сборка проекта](../README.md#сборка-и-запуск)).

Для запуска CLI укажите путь к файлу базы данных:
```bash
./build/rawdb_cli /path/to/my_database
```

Если путь не указан, CLI автоматически создаст/откроет базу данных в папке `rawdb_data` в текущей директории:
```bash
./build/rawdb_cli
```

*(Обратите внимание: режим In-Memory `:memory:` в данный момент CLI поддерживает ограниченно и работает через fallback-директорию `rawdb_memory_fallback`)*

## Выполнение SQL запросов

CLI поддерживает **многострочный ввод**. Вы можете писать длинные запросы на нескольких строках. Терминал не отправит запрос на выполнение до тех пор, пока вы не поставите **точку с запятой (`;`)**.

Пример сессии:
```text
rawdb> CREATE TABLE users (id INT32, name VARCHAR);
+---------+
| created |
+---------+
| true    |
+---------+
(1 row)
rawdb> INSERT INTO users VALUES (1, 'Alice');
+---------------+
| rows_inserted |
+---------------+
| 1             |
+---------------+
(1 row)
rawdb> SELECT * FROM users
  ...> WHERE id = 1;
+----+-------+
| id | name  |
+----+-------+
| 1  | Alice |
+----+-------+
(1 row)
```

> **Важно**: Если вы сделали опечатку и "застряли" в режиме ожидания `...>`, просто введите `;` и нажмите Enter, чтобы сбросить буфер (запрос завершится с синтаксической ошибкой, но терминал вернется в исходное состояние).

## Мета-команды

Помимо SQL-запросов, CLI поддерживает служебные мета-команды. Мета-команды **не требуют** точки с запятой в конце и выполняются мгновенно.

| Команда | Описание |
|---|---|
| `.help` | Вывести список всех доступных мета-команд. |
| `.tables` | Показать список всех таблиц в текущей открытой базе данных. |
| `.schema <table_name>` | Вывести структуру конкретной таблицы (колонки и их типы) в формате SQL-запроса `CREATE TABLE`. |
| `.exit` или `.quit` | Безопасно закрыть соединение с БД и выйти из терминала. |

*Примечание: для удобства (UX) вы также можете использовать слова `help`, `exit` или `quit` (без точки) как синонимы соответствующих мета-команд, при условии, что буфер ввода в данный момент пуст.*
